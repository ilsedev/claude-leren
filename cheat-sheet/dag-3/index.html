Dag 3: /rewind

Terug naar een eerder punt in het gesprek. Twee keer Esc doet hetzelfde.

Wat het doet

Claude Code bewaart vóór elke prompt een momentopname van de bestanden die Claude bewerkt. Met /rewind, of twee keer Esc bij een leeg invoerveld, kies je een eerder bericht en zet je het gesprek, de code of allebei terug naar dat moment.

Wanneer gebruik je het

  • Claude heeft iets aangepast dat je toch niet wilt.
  • Je wilt iets riskants proberen en weten dat je terug kunt.
  • Je wilt een vraag anders stellen, alsof de eerste poging nooit gebeurd is.

Zo oefen je

  1. Laat Claude een kleine wijziging doen in een bestand.
  2. Druk twee keer op Esc (of typ /rewind).
  3. Kies het bericht van vóór de wijziging.
  4. Kies Restore code and conversation. Je prompt staat weer klaar om aan te passen.
