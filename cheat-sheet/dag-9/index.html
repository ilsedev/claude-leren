Dag 9: /skills

Bekijk je skills en zet ze aan of uit. Elke skill kost een beetje context.

← Cheat sheet

Wat het doet

Een skill is een pakketje instructies voor een bepaald soort taak. Claude ziet van elke skill steeds de naam en beschrijving; de volledige inhoud laadt pas als hij de skill gebruikt. /skills toont de lijst en laat je per skill kiezen hoe zichtbaar hij is.

Wanneer gebruik je het

  • Je wilt weten welke skills je hebt.
  • Je wilt skills die je nooit gebruikt uitzetten.
  • Claude pakt een skill op momenten dat je dat niet wilt.

Zo oefen je

  1. Typ /skills. Typ letters om de lijst te filteren.
  2. Druk op t om te sorteren op hoeveel tokens een skill kost.
  3. Kies een skill en druk op Spatie om de stand te wisselen: aan, alleen naam, alleen voor jou, of uit.
  4. Druk op Esc om op te slaan.

Voorbeeld

/skills
Let opElke skill in de lijst kost bij elke beurt een beetje context, ook als je hem nooit gebruikt. Veel skills betekent dus hogere vaste kosten. /skill-doctor laat per skill zien wat hij kost en hoe vaak hij gebruikt wordt.
